# Bravo Hub

Hub desktop de inteligências artificiais da Bravo. Reúne geração de imagem, vídeo e upscale num só aplicativo, com um canvas de nodes (no estilo do Spaces) pra montar fluxos de criação, e chama cada modelo direto pela API oficial do fabricante.

Status: início do projeto. Veja `docs/arquitetura.md` pro plano.
